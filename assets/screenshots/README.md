# Project Screenshots

Store the important screenshots of SETU in this folder.

## Recommended screenshots (SETU)

- `01-landing.png` — the landing page (the plan-vs-reality hero)
- `02-timeline.png` — the live Timeline / Gantt (planned vs actual, delay badges, "no report yet")
- `03-telegram-capture.png` — a supervisor sending a voice note / text to the Telegram bot
- `04-review-inbox.png` — the Review inbox: raw message beside the matched activity, with the reason
- `05-receipt.png` — the tamper-evident receipt (original message · confidence · audit hash)
- `06-diary-photo.png` — a photographed diary page being read and matched
- `07-ask-project.png` — "Ask your project" answering in plain language with a chart
- `08-export.png` — the P6-importable handover / export
- `09-multilingual.png` — the UI in Hindi / Assamese (language switch)

## Naming convention

Use clear, ordered names such as `01-landing.png`, `02-timeline.png`, …

Do **not** upload screenshots containing passwords, API keys, tokens, connection
strings, or other sensitive information (blur anything sensitive first).

## Adding screenshots to the README

Display important screenshots in the main `README.md` using a relative path:

```md
![SETU live Timeline](assets/screenshots/02-timeline.png)
```
